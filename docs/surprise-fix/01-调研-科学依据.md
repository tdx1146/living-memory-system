## 一、FEP 理论要点（正式定义 + 来源）

### 1.1 Surprise（惊讶度/自信息）的正式定义

**Surprise = 感官状态的负对数边缘概率：**

```
surprise = -ln P(o)
```

- 离散情形：`P(o)` 是概率，`0 ≤ P(o) ≤ 1`，所以 **surprise ∈ [0, +∞)**。这是信息论中"自信息"的标准定义——越不可能的事件，自信息越大。
- 连续情形：`p(o)` 是**密度**（单位空间上的概率），密度可以 > 1，所以 `-ln p(o)` 严格说可以 < 0。FEP 文献中通常仍按"惊讶 ≥ 0"的直觉使用它，但严格保证 ≥ 0 的是离散形式。
- 来源：Friston (2010) *Nat Rev Neurosci* "The free-energy principle: a unified brain theory?"；Buckley et al. (2017) *J Math Psychol*（arXiv:1705.09156）；Spisak & Friston (2026) eq.(3) 上下文。

**直觉语义：惊讶度 = "这个感官输入有多出乎意料"——只与预测的失败程度有关，恒非负（离散情形）。**

### 1.2 变分自由能（VFE）与 surprise 的关系

**变分自由能（VFE）的定义（Spisak & Friston 2026 论文 eq.3，也是全 FEP 的标准定义）：**

```
F(s,a,μ) = E_q(η)[ ln q(η) − ln p(s,a,η) ]
```

展开可得（这是 FEP 最核心的恒等式）：

```
F = D_KL[ q(η) || p(η|o) ]  +  ( −ln p(o) )
  = 复杂度(KL ≥ 0)          +  surprise(≥ 0, 离散)
```

即 **VFE = 复杂度 + 惊讶度 = KL散度 + surprise**，由此得到两个定理：

1. **F ≥ surprise**：变分自由能永远是惊讶度的**上界**（因为 KL ≥ 0）。最小化 F ⇒ 最小化 surprise 的上界 ⇒ 间接最小化 surprise。这就是"自由能最小化 = 惊讶最小化"的数学依据。
2. **VFE 的符号**：在密度**规范化**的前提下（q、p 都是合法概率/密度、常数项齐全），离散情形 **F ≥ 0**。
3. **但实践中 F 可以是负的**，原因有二：
   - **实现丢弃常数**：熵项 `E_q[ln q]`、分布的归一化常数（log-normalizer，如高斯的 `0.5·ln|2πΣ|`、连续伯努利的 `φ(b)=ln(sinh b / b)`）被省略后，F 变成"未规范化的能量"，与真 VFE 只差一个加法常数，**无下界，可为负**。Friston 本人的大量实现（变分滤波、DCM）报告的 free energy 就是负值——因为只差常数，**梯度 Δ = -∇F 不受影响，所以对学习无害**。
   - **连续密度可 > 1**：即使规范化，`-ln p(o)` 在密度值 > 1 处也为负。
   - 结论：**"自由能可以是负的"这句话，对"能量泛函（未规范化）"成立，对"规范化 VFE"不成立（离散情形 F ≥ 0）。** 当前 LMS 计算的是前者。

### 1.3 F = 准确性 − 复杂度 的标准分解

预测编码/主动推断文献把 VFE 写成（Bogacz 2017 *J Math Psychol* 教程；Spisak & Friston eq.14）：

```
F = D_KL[q(σ_i)||p(σ_i)]          （complexity，≥ 0，先验约束）
    − E_q[ ln p(σ_{\i} | σ_i) ]   （accuracy，预期对数似然）
```

- **准确性项**（在 LMS 中对应 `0.5·Σ π_i(σ_i − s_i)²`）：感官预测误差的加权平方和，**恒 ≥ 0**。
- **复杂度项**：后验偏离先验的 KL 代价，恒 ≥ 0。
- 神经网络实现（预测编码）里，梯度下降 F 产生的更新就是"误差单元沿精度加权的预测误差传播"——**precision-weighted prediction error 是主动推断的定量核心**。

### 1.4 Precision（精度）在主动推断中的作用

- **Precision = 逆方差**（高斯情形：`π = 1/σ²`）。它衡量一个预测误差通道有多"可信"。
- 主动推断中，预测误差被 **precision 加权**：`error × π`（或二次型 `εᵀΠε`）。高 precision ⇒ 该通道的误差被放大处理 ⇒ 该方向"更值得学习/更值得关注"。
- 注意力的神经科学对应：**注意力 = 对预测误差精度的优化**（Feldman & Friston 2010 "Attention, uncertainty, and free-energy"）。
- 学习速率语义：高 precision = 高信任 = 该方向学习快——**这与 LMS ARCHITECTURE.md §6.1 的表述完全一致**，LMS 的 precision 设计符合主动推断。
- 来源：Feldman & Friston (2010) *Front Hum Neurosci*；Friston (2008) *PLoS Comput Biol* "Hierarchical models in the brain"；Parr, Pezzulo & Friston (2022) MIT Press 专著。

### 1.5 吸引子网络：能量函数与自由能的关系

- **Hopfield 能量**（Hopfield 1982）：`E(σ) = −0.5·Σ_ij J_ij σ_i σ_j − Σ_i b_i σ_i`。系统状态按能量下降方向演化，收敛到能量极小 = 吸引子。
- **Boltzmann 先验**：`p(σ) ∝ exp(−E(σ)) = exp(bᵀσ + σᵀJσ)`——**状态先验的负对数就是能量**（Spisak & Friston eq.13）。能量极小 = 先验概率极大 = "最自然的吸引子"。
- **Spisak & Friston 2026 的核心结果**：对"深度特定划分"系统做 VFE 最小化，
  - 推断动力学自动涌现为 **Boltzmann/Hopfield 式更新**：`σ_i = L(b_i + Σ_j J_ij σ_j)`（eq.20），其中 **L 是 Langevin 函数 = 连续伯努利（CB）分布的均值**（附录4；CB 分布见 Loaiza-Ganem & Cunningham 2019）。**LMS 的 `infer()`（`b_q = bias + J@σ; σ = langevin(b_q)`）与 eq.20 逐项吻合 ✅**
  - 学习规则自动涌现为 **Hebbian/anti-Hebbian 对比规则**：`ΔJ_ij ∝ σ_iσ_j（观测相关）− L(u_i)σ_j（预测相关）`（eq.24-25），结构上接近 Sanger 规则 ⇒ 吸引子近似正交化，抗灾难性遗忘。**LMS 的 `learn()` 用的是 Hebbian − 正交化压力 − 权重衰减，没有显式的 anti-Hebbian 项**（见 §2.1 差距表）。
  - "能量"与"自由能"的关系：能量 = 未规范化的 −ln p（无下界）；自由能 = 能量 + 熵/归一化常数（规范化后 ≥ 0）。吸引子动力学最小化的"自由能景观"，其**形状**由能量决定，但**数值**（惊讶度意义上的）来自规范化后的 VFE。

## 二、当前实现与理论的差距分析

### 2.1 LMS 公式逐项对照

LMS 实际计算（`attractor.py::_compute_free_energy`）：

```
F = −0.5·σᵀJσ − bᵀσ          （能量项）
  + 0.5·Σ π_i(σ_i − s_i)²     （准确性项）
  + 0.5·complexity_weight·‖J‖²（复杂性项）
```

| 分量 | 与 FEP 的关系 | 评估 |
|------|--------------|------|
| 能量项 `−0.5σᵀJσ − bᵀσ` | = Hopfield/Boltzmann 状态先验的负对数（Spisak-Friston eq.13 的指数部分） | ✅ 有理论依据，是"先验复杂度"的一部分 |
| 准确性项 `0.5Σπ(σ−s)²` | = precision-weighted prediction error（主动推断标准量） | ✅ 有理论依据；但注意：Spisak-Friston 原文里感官证据是**加进 bias** 的（eq.8：`σ_i|s_ij ~ CB(b_i + s_ij)`），不单独设准确性项。LMS 用的是**预测编码风格**（似然项直接进 F）。这是合法的生成模型变体（高斯似然），但**不是论文原文的 F**，是工程混合 |
| 复杂性项 `0.5·c·‖J‖²` | 权重衰减 = 参数的 Gaussian 先验（贝叶斯正则） | ✅ 工程合理；但论文原文的复杂度是 `D_KL[q(σ)||p(σ)]`（状态 KL），**正交性来自对比学习规则本身**，不是显式 ‖J‖² 惩罚。LMS 用权重衰减代替，方向一致、形式不同 |
| **缺失**：`E_q[ln q]` 熵项、CB 的 log-normalizer `φ(b)=ln(sinh b/b)`、各归一化常数 | 这些把"能量"变成"自由能" | ❌ 缺失 ⇒ 当前 F 是**变分能量（variational energy）**，不是规范化的 VFE |

**判定：LMS 的 F 是一个合法的"变分能量泛函"**（状态先验能量 + 精度加权预测误差 + 参数正则），作为**学习目标**（ΔJ = −η∇F、σ 动力学收敛）完全成立，且与母本论文的推断动力学一致。但它**不是** VFE 的完整形式，**更不是 surprise**。

### 2.2 为什么实测 F = −36.32（负值）是结构性的

量级分析（N=256 节点、input_dim=64、σ∈(−1,1)、π∈[0.1,10]）：

- 能量项：`|0.5·σᵀJσ| ≤ 0.5·‖J‖₂·‖σ‖² ≈ 0.5·40·256 ≈ 5000` 量级（J 范数 40 时）。σ 与 J 对齐（状态落在吸引子内）时 `σᵀJσ > 0` ⇒ 能量项 **大幅为负**。
- 准确性项：`0.5·π·Σ(σ−s)² ≤ 0.5·10·64·4 = 1280`，常态 ~1~100。
- 复杂性项：`0.5·0.01·1600 = 8`，可忽略。

**F 被能量项主导。** 系统越是"安稳地待在熟悉的吸引子里"（对应熵 1.00 的低熵集中态、coherence 0.977 的高稳定目的），`−0.5σᵀJσ` 越负，F 越负。-36.32 就是"系统深深陷入吸引子"的读数。**这不是 bug，是这个公式的必然结果。**

### 2.3 "惊讶度"和"自由能"是不是一回事？——不是

| 概念 | 定义 | 符号 | 语义 |
|------|------|------|------|
| **Surprise（惊讶度）** | `−ln P(o)` | ≥ 0（离散） | 感官输入有多**出乎意料** |
| **VFE（变分自由能）** | `E_q[ln q − ln p(o,η)]` | ≥ 0（规范化）；能量泛函可负 | 惊讶度的上界 = 复杂度 + 惊讶度 |
| **能量泛函（LMS 的 F）** | 丢常数/丢熵的 VFE | **无下界，可负** | 学习目标；负 = 深陷吸引子（内部和谐），≠ 预测失败 |

**LMS 的 -36.32 实际度量的是"内部和谐度"（负能量），不是"感官惊讶度"。** 它甚至与预测误差方向相反：一个**又深陷吸引子、又猜错输入**的状态（能量项很负 + 准确性项很高），F 仍然为负——真实的惊讶被能量项掩盖了。这就是把能量当惊讶度的**具体失效模式**。

值得强调：**本地 2026-07-31 分析文档自己写的定义是对的**——"惊讶度 = prediction_error × precision"——那正是准确性项。实现把惊讶度接到了完整 F 上，是**实现与文档的偏离**。

### 2.4 norm 归一化（F/‖J‖_F）是否科学？——不科学，应移除

- **无 FEP 依据**：VFE 没有"除以参数范数"的尺度不变性。F = 各分量之和的加性结构、F ≥ surprise 的上界结构，都会在任意非线性重标定下被破坏。
- **方向性扭曲**：准确性项**不随** ‖J‖ 缩放，但 F/‖J‖ 会把准确性项也除以 ‖J‖——J 越大，预测误差的贡献被压得越小。**"惊讶度"随模型变复杂而系统性缩水，这恰好是反的。**
- **治本方案已存在**：`LMS_J_TARGET_NORM=40` 的 J 范数钳制（= 参数先验/复杂度上界）才是正确手段。但**当前实现把 J 钳制 gate 在 `norm_surprise` 开关后面（默认关）**——"2026-08-10 设计回归：治本而非开关"的意图没有真正生效。即使钳制生效，能量项仍是 O(N·‖J‖) 量级（见 2.2），钳制不解决能量项主导问题。
- **如果真要跨尺度可比性**，正确做法是**按节点数归一**：准确性项 ÷ input_dim（= 均方预测误差 MSE，天然无量纲），或能量项 ÷ N（每节点平均）。这是标准的、有量纲依据的归一化。

### 2.5 附带发现（同一根因的三个下游症状）

1. **回放权重被清零**：`memory.py` 里 `weight = replay_weight * max(min(surprise, cap), 0)`——F < 0 时全部权重 = 0，"重要性加权回放"退化；排序回放用的又是被能量项污染的 F，选出来的"高惊讶"记忆实际是"深陷吸引子"的记忆。而神经科学依据恰恰是"**回放按预测误差优先**"（DREAM_ENGINE_DESIGN §2.1 引用：海马-纹状体回放优先更新预测误差）——现在排序的物理量错了。
2. **做梦采样语义错位**：`w_i = exp(β·surprise_i)/Σexp(...)`——F 恒为负时 `exp(βF)` 全部塌向 0，软max 退化为近似均匀；相对排序虽保留，但"高惊讶 → 高权重"的直觉映射被破坏。
3. **目的层代理错误**：`purpose._compute_per_dim_surprise` 用 `|σ_i|`（感官节点激活强度）当惊讶度代理——**激活强度 ≠ 惊讶度**（高激活可能是"熟悉且强烈的模式"，恰不惊讶）。正确量是逐维精度加权预测误差 `π_i(σ_i − s_i)²`。换成它之后，"常遇到→误差小→惊讶低→precision 衰减"的习惯化逻辑才真正自洽。

## 三、明确建议（惊讶度公式、符号约定、开关处理）

### A. 核心建议：语义拆分，一个量一个名字

```
surprise（惊讶度，报告/回放/目的层/做梦用，恒 ≥ 0）
    = accuracy 项 = 0.5 · Σ_{i∈sensory} π_i · (σ_i − s_i)²        ← precision-weighted prediction error

free_energy（自由能/变分能量，学习目标用，可负）
    = −0.5σᵀJσ − bᵀσ + 0.5·Σπ_i(σ_i−s_i)² + 0.5·c·‖J‖²           ← 现有 F，保留原样，改名
```

- `Activation` 增加/改两个字段：`surprise`（= 准确性项）与 `free_energy`（= 现有 F）。`surprise` 字段保持 ≥ 0。
- 逐维惊讶度：`surprise_i = π_i·(σ_i − s_i)²`，供目的层/注意力使用。
- 可选可读性指标：`MSE = (1/input_dim)·Σ(σ_i−s_i)²`（无量纲、跨尺度可比）。
- **负值不"修"**——F 是能量，本来就该可负；要修的是**命名**：把"负能量"叫成"惊讶度"才是错误。文档层面（decoder 解读、聊天记录、ARCHITECTURE.md）同步改为"自由能（能量）"表述。

### B. 若想要 FEP 意义上"非负的总量"，两个选项

1. **轻量版（推荐）**：报告 `surprise(accuracy) ≥ 0` 与 `complexity = 0.5·c·‖J‖² ≥ 0` 两个分量；需要总量时用两者之和（都 ≥ 0，对应 FEP 的 accuracy + complexity 分解）。
2. **论文版（完整）**：按 Spisak & Friston eq.(18)/(23) 实现 per-node VFE，**加回连续伯努利的 log-normalizer `φ(b) = ln(sinh(b)/b)`**——此时 VFE 是 Bregman 散度，**数学上恒 ≥ 0**，且与论文逐项对应。代价：F 变成 N 个节点值，感官 clamping 需改为"bias 扰动"式（论文 eq.8）或保留高斯似然项并补齐其熵项/常数。若追求"F 严格非负 + 完全忠于母本论文"，选这个。

### C. 开关处理（具体到代码语义）

| 现有机制 | 建议 |
|---------|------|
| `LMS_NORM_SURPRISE=1` 时 `F /= ‖J‖_F` | **移除**（或降级为仅诊断输出）。无 FEP 依据、扭曲准确性项。 |
| `LMS_J_TARGET_NORM=40` J 范数钳制（现在被 gate 在 norm_surprise 开关后，默认关） | **与 norm 开关解耦、无条件生效**。这是参数先验（复杂度有界），是治本机制，应默认开启。 |
| 跨尺度可比性需求 | 用 ÷input_dim（MSE）或 ÷N（每节点平均），不要用 ÷‖J‖。 |
| 温度缩放（可选） | 若想给能量项做物理意义上的缩放，用 Langevin 温度 `F/T`（βF），这是统计力学里能量→自由能的标准缩放，比 ÷‖J‖ 有依据。 |

### D. 下游一致性修正（同一根因）

- `memory.py` 回放：`surprise` 改用准确性项后，`max(surprise,0)` 钳制自然失效于负值问题；排序 = 按预测误差排序，**与"回放按预测误差优先"的神经科学依据对齐**。
- 做梦引擎软max：`exp(β·surprise)` 输入恒 ≥ 0，权重语义恢复"高惊讶 → 高权重"。
- 元可塑性（meta）的 surprise 趋势：改用准确性项，避免被能量项污染（能量项随 J 增长会制造虚假的"惊讶趋势"）。
- 目的层：`_compute_per_dim_surprise = π_i·(σ_i − s_i)²` 映射到 `[precision_min, precision_max]`，替换现在的 `|σ_i|` 代理。
- 验证建议（只读任务不做改动，供实施后检验）：
  1. 对比 `surprise(accuracy)` 与 `F` 对同一批记忆的排序差异——预期显著不同，且 accuracy 排序与人工标注的"意外程度"一致；
  2. 统计 `max(surprise,0)` 被触发的比例（当前负值下应接近 100%）；
  3. 观察 `-F` 与 accuracy 的相关性——若强相关说明系统主要处于"安稳且正确"态；若弱相关，说明"安稳但猜错"的状态确实存在，印证拆分必要性。

## 四、对调研问题的直接回答

1. **surprise 的正式定义**：`surprise = −ln P(o)`（自信息），离散情形恒 ≥ 0；VFE 是它的上界（F ≥ surprise）。来源：Friston 2010；Buckley et al. 2017；Spisak & Friston 2026 eq.3。
2. **precision 的作用**：逆方差；对预测误差做精度加权（precision-weighted prediction error）；高 precision = 高信任 = 该方向学习快 = 注意力的神经对应。来源：Feldman & Friston 2010；Friston 2008；Parr et al. 2022。
3. **吸引子网络的能量与自由能**：Hopfield 能量 = 状态先验的负对数；FEP 推导下，吸引子动力学 = VFE 梯度下降的涌现结果（Langevin 激活 + Hebbian/anti-Hebbian 学习）。LMS 的推断动力学与母本论文 eq.20 完全一致。
4. **LMS 公式是否符合 FEP 标准形式**：作为**学习目标**符合（能量泛函，梯度语义正确）；作为**惊讶度**不符合（缺熵项与归一化常数 ⇒ 非 VFE；能量项主导 ⇒ 数值为负且与预测误差方向脱钩）。FEP 里**规范化的 VFE ≥ 0**（离散），**能量泛函可负**；"惊讶度"≠"自由能"。`F/‖J‖` 归一化不科学，应移除。
5. **建议**：惊讶度 = 准确性项（恒 ≥ 0）；自由能 = 现有 F（可负，仅作学习目标）；命名分离；J 钳制无条件生效；目的层/回放/做梦全部改用准确性项语义；若要 FEP 级非负，加回 CB log-normalizer（Bregman 形式）。
