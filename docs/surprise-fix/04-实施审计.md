## 必须修复项清单

1. **【G1·glue 仓】空窗口 min(w) 崩溃**（高优先级，一行级修复）：
   - 位置：`interfaces/services/integration_service.py` L191-192
   - 现状：`lo, hi = min(w), max(w) if w else 0.0`——`min(w)` 无条件执行，`self.lms is None`（未配置）或首调即 fetch_context 失败时 w 为空 → `ValueError` → recall() 500。旧代码此场景安全（fail-open），G1 使其退化为 fail-crash。
   - 修复建议（与设计"退化→中性 0.5"意图一致）：
     ```python
     if not w:
         surprise_norm = 0.5          # 空窗口（无 LMS 数据/首调失败）→ 中性激励
     else:
         lo, hi = min(w), max(w)
         if hi - lo > 1e-8:
             surprise_norm = min(max((surprise - lo) / (hi - lo), 0.0), 1.0)
         else:
             surprise_norm = 0.5      # 窗口退化（无起伏）→ 中性激励
     ```
   - 配套：补单测（空窗口 → surprise_norm==0.5；单元素窗口 → 0.5）。
   - 说明：此缺陷源自设计 v1.1 §2.2 定案代码本身（设计同样未处理空窗口），实现照抄了设计；按"设计意图"修复即可，无需改设计。
