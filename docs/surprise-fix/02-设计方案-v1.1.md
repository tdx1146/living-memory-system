## 1. 目标与范围

### 1.1 方案 A 定义（一句话）

**一个量一个名字**：

```
surprise（惊讶度，恒 ≥ 0，供报告/回放/目的层/做梦/元可塑性使用）
    = accuracy 项 = 0.5 · Σ_{i∈sensory} π_i · (σ_i − s_i)²      ← precision-weighted prediction error

free_energy（自由能 = 未规范化变分能量，可负；严格 VFE ≥ 0 需 Bregman 形式 = 后续项 §3.6；仅供学习目标与诊断）
    = −0.5·σᵀJσ − bᵀσ + 0.5·Σπ_i(σ_i−s_i)² + 0.5·complexity_weight·‖J‖²   ← 现有 F，原样保留，改名
```

- **负值不"修"**：F 是能量泛函（未规范化 VFE），本来就该可负（实测 -36.32 = "系统深陷吸引子"的内部和谐度，不是预测失败）。要修的是**命名**——把"负能量"叫成"惊讶度"才是错误。
- 理论依据（论文 v2 eq.(3)，v1/v2 编号一致）：`F(s,a,μ) = E_q[ln q(η) − ln p(s,a,η)]`；展开得 `F = D_KL[q‖p(η|o)] + (−ln p(o)) = complexity + surprise`，即 **F ≥ surprise，surprise = −ln P(o) ≥ 0**（离散情形）。LMS 当前把整个能量泛函命名为 surprise，语义错位。
- ⚠️ 限定（v1.1 修订）：上述 F ≥ surprise 恒等式只对**规范化** VFE（含熵项与归一化常数）成立；LMS 的 F 缺 `E_q[ln q]` 与 log-normalizer，是**未规范化变分能量**，从未满足该上界——本处仅作命名分离的理论背景引用，**不作为任何数值论证依据**（§3.3 已删除基于该上界的论证）。

## 2. 数据模型设计

### 2.1 Activation 结构变更（`core/types.py`）

```python
@dataclass
class Activation:
    """海马体激活态：吸引子网络的输出。

    属性:
        state: 节点激活值 [num_nodes]，(-1, 1)。
        entropy: 激活熵。
        surprise: 惊讶度 = 准确性项（precision-weighted prediction error），

            仅供学习目标与诊断；默认 0.0 保证旧构造点兼容。
        per_dim_surprise: 逐维惊讶度 π_i·(σ_i−s_i)² [input_dim]，
            供目的层/注意力使用；默认 None（旧构造点兼容）。
        mse: 均方预测误差 (1/input_dim)·Σ(σ_i−s_i)²，跨尺度可比；
            默认 None（旧构造点兼容）。

    entropy: float
```

```python
# 现状：surprise_norm = min(surprise / 20.0, 1.0)
#   → 准确性项 O(1~100) 下恒饱和到 1.0，LMS 弱激励变常数；

    surprise_norm = min(max((surprise - lo) / (hi - lo), 0.0), 1.0)  # 相对惊讶度
```

语义：`surprise_norm` 变为"相对惊讶度"（本窗口内排位），对任意量级稳健，且消除现存负值惩罚缺陷。备选：`entropy_ratio = entropy / ln(num_nodes)`（实现更简单，但激励绑定到熵而非惊讶）——**推荐窗口 min-max**。此定案同时统一原设计三处矛盾表述（§2.2 旧"第 3 批 commit"、§6.2 旧"C4 后置项"、§6.1 旧未列入）为：**commit G1，独立仓库、必做、可后置不取消**。

**快照兼容**：快照保存的是 J/bias/sigma/precision/history/memory 潜变量与 `_buffer` 的 `(state, surprise)` 元组、episodic 条目——**不保存 Activation**。旧快照恢复后，buffer 里的 surprise 是旧 F 值（多为负），与新产生的准确性项（≥0）混存：排序时旧值自然沉底（=低重要），softmax 加权时旧值权重≈0，**行为可接受**，无需迁移。旧 `Activation` 类不存在于快照中，无 pickle 兼容问题。

### 2.3 逐维惊讶度暴露方式

- 计算位置：**`attractor.infer()` 内**（它同时持有 σ、s、π），产出 `per_dim_surprise = π_i·(σ_i−s_i)²`（仅 sensory 维度，形状 `[input_dim]`）写入 Activation。
- 消费方：`purpose._compute_per_dim_surprise(activation)` 优先读 `activation.per_dim_surprise`；为 `None`（旧测试手搓的 Activation）时回退现有 `|σ_i|` 代理——**行为降级但绝不崩溃**。
- 不新增独立 API 字段（避免契约膨胀）；如需调试可在 `last_per_dim_mean/std` 加入 status（可选）。

## 3. 公式与算法设计（严格按论文）

### 3.1 surprise（准确性项）——精确实现位置

`core/hippocampus/attractor.py` 新增方法（放在 `_compute_free_energy` 旁）：

```python
def _compute_surprise(self, sigma: torch.Tensor,
                      sensory_input: torch.Tensor,
                      precision: torch.Tensor) -> float:
    """惊讶度 = 准确性项 = precision-weighted prediction error（恒 ≥ 0）。

    surprise = 0.5 · Σ_{i∈sensory} π_i · (σ_i − s_i)²
    = 主动推断中"precision-weighted prediction error"的标准二次型
      （Feldman & Friston 2010；Spisak & Friston v2 的 accuracy 分量——
      与论文 eq.(14) 逐节点 VFE 中的期望对数似然项构成**结构性对应
      （高斯似然类比）**：同为"期望对数似然"分量，但 LMS 用高斯二次型、
      论文用连续伯努利（CB）参数化，**非字面同一公式**，措辞以"类比"为准）。
    注意：只对感官节点（前 input_dim 个）求和；非感官节点无外部参照，
    不进入惊讶度。σ、s 均在 (-1,1) 附近、π ∈ [0.1, 10]，故恒 ≥ 0。
    """
    sensory_error = sigma[:self.input_dim] - sensory_input
    return float(0.5 * torch.sum(precision * sensory_error ** 2).item())

def _compute_per_dim_surprise(self, sigma, sensory_input, precision) -> torch.Tensor:
    """逐维惊讶度 surprise_i = π_i·(σ_i−s_i)²，形状 [input_dim]。"""
    sensory_error = sigma[:self.input_dim] - sensory_input
    return (precision * sensory_error ** 2).detach().clone()
```

`infer()` 内改动（现 L246-249）：

```python
# 计算惊讶度（准确性项）、自由能、逐维惊讶度、MSE
surprise = self._compute_surprise(sigma, sensory_input, precision)
free_energy = self._compute_free_energy(sigma, sensory_input, precision)
per_dim_surprise = self._compute_per_dim_surprise(sigma, sensory_input, precision)
mse = float(torch.mean((sigma[:self.input_dim] - sensory_input) ** 2).item())
entropy = self._compute_entropy(sigma)

return Activation(state=sigma, entropy=entropy, surprise=surprise,
                  free_energy=free_energy,
                  per_dim_surprise=per_dim_surprise,
                  mse=mse)
```

1. **无 FEP 依据**：VFE 没有"除以参数范数"的尺度不变性（调研报告 §2.4）；`F/‖J‖` 是自造的非法归一化，其加性结构（能量项 + accuracy + complexity）在任意非线性重标定下都会被破坏。
2. **扭曲准确性项**：准确性项不随 ‖J‖ 缩放，但 `F/‖J‖` 把准确性项也除以 ‖J‖——J 越大，预测误差贡献被压得越小，"惊讶度"随模型变复杂而系统性缩水，方向恰好相反。

`api/config.py`、`api/server.py` L412 附近引用 `norm_surprise` 仅为配置透传与审计，属性保留即可零破坏。

### 3.6 Bregman 形式（论文 v2 eq.(13/14) 逐节点 VFE + eq.(25)）——本期不做，记为后续项

**结论：本期不做。** 理由：

1. 需要加回连续伯努利（CB）的 log-normalizer `φ(b) = ln(sinh(b)/b)`，并逐节点计算 per-node VFE（F 从标量变 N 维向量），改动面波及 `_compute_free_energy`、快照语义、所有下游读数——与本方案"命名分离、最小改动"的目标冲突。
2. 其收益（F 数学上恒 ≥ 0）只影响**诊断**观感；学习目标（梯度 Δ = −∇F）在能量泛函与 Bregman VFE 下**等价**（差一个与 σ 无关的常数/熵项），Friston 本人在变分滤波/DCM 实现中也报告负 F。

### 4.2 dream_engine softmax（需改动：输入标准化 + 零精度陷阱）

- **文件**：`core/hippocampus/dream_engine.py`
- **问题 1（零精度陷阱）**：`_idle_infer` 用 `idle_precision = zeros` 推断（做梦=纯先验采样）。precision=0 ⇒ 准确性项 `0.5·Σπ(σ−s)² = 0` ⇒ **做梦时 surprise 恒为 0**，avg_surprise、buffer 回填、遗忘修剪均值全部退化。
  - **修复**（`_idle_infer` 末尾）：以"被回放的种子记忆"为参照计算重构误差：
    ```python
    # 做梦时的惊讶度 = 生成式回放对种子记忆的重构误差（π=1）
    seed_sensory = sensory_input[:self.attractor.input_dim]  # 种子记忆的感官部分
    replay_error = activation.state[:self.attractor.input_dim] - seed_sensory
    activation.surprise = float(0.5 * torch.sum(replay_error ** 2).item())
    activation.per_dim_surprise = (replay_error ** 2).detach().clone()
    ```
    语义："回放漂移越大的记忆越值得巩固"——与神经科学（高预测误差优先回放）一致。
  - 注意：`sensory_input` 是 `[num_nodes]` 记忆态，种子感官部分取前 `input_dim` 个节点（与在线感官节点定义一致）。

- **问题 2（softmax 退化）**：准确性项量级 O(1~100)，`exp(β·surprise)`（β=5.0）经 max 减法后除最大项外全部塌向 0 → 采样退化为近似 argmax，做梦回放垄断单条记忆。
  - **修复**（`_sample_by_surprise` L466-469，修订 v1.1）：softmax 输入做**缓冲区内标准化 + z 截断**（尺度无关，无需改配置；z 截断防重尾离群）：
    ```python
    mean_s = surprises.mean()
    std_s = surprises.std()
    if std_s > 1e-8:
        z = (surprises - mean_s) / std_s
    else:
        z = torch.zeros_like(surprises)
    z = z.clamp(-3.0, 3.0)      # v1.1：z 截断，防重尾离群（z≈10）下 exp(βz) 退化为 argmax
    shifted = beta * z          # z 无量纲；β 默认降至 1.0（可配置 surprise_beta），"强但不退化"
    weights = torch.exp(shifted)
    weights = weights / weights.sum()
    ```
  - **推荐 (a)+(b) 组合落地（审计 §3.2 建议）**：(a) z 截断 `clamp(±3)` 为主方案（对任意量级与重尾分布稳健）；(b) `surprise_beta` 默认从 5.0 降至 **1.0**（改配置一行，作为第二道保险）。备选 (c)：`tanh(z)` 有界映射，等价于 (a)，实现可任选其一。

### 4.4 purpose.py 目的层（需改动）

- **改动 A**：`_compute_per_dim_surprise`（L134 起）优先读 `activation.per_dim_surprise`：
  ```python
  def _compute_per_dim_surprise(self, activation: Activation) -> torch.Tensor:
      """逐维惊讶度 = π_i·(σ_i−s_i)²（由 attractor.infer 填充），映射到
      [precision_min, precision_max]。
      回退：activation.per_dim_surprise 为 None（旧构造点/旧测试）时，
      沿用 |σ_i| 激活强度代理（行为降级，不崩溃）。"""
      raw = activation.per_dim_surprise
      if raw is None:
          sensory_activation = activation.state[:self.input_dim].abs().to(self.device)
          scale = self.precision_max - self.precision_min
          return self.precision_min + sensory_activation * scale
      raw = raw.to(self.device)
      # 单调饱和映射：surprise_i ∈ [0,∞) → [precision_min, precision_max]
      # tanh(raw / k)：k 为尺度常数（默认 1.0，可配置 per_dim_surprise_scale）。
      # 理由：|σ| 代理天然 ∈(0,1)，而 π(σ−s)² 无量纲上限，需有界单调映射
      # 才能继续喂给 EMA 与 clamp。
      k = self.per_dim_surprise_scale  # 新构造参数，默认 1.0
      mapped = self.precision_min + (self.precision_max - self.precision_min) \
               * torch.tanh(raw / k)
      return mapped
  ```

  - 习惯化衰减（L327 之后 `habituation` 相乘）保持在映射之后，逻辑不变："常遇到→误差小→惊讶低→precision 衰减"自洽；注：误差小本身已反映熟悉，habituation 再乘一次属**双重复合**，冗余不有害（审计 §3.6 建议注释说明）。
- **改动 B**：`adjust()` 的全局缩放（L338-339）：

### 5.3 验证实验（脚本思路，只读任务不做）

## 7. 设计决策摘要（≤10 行）

1. surprise 字段保留名、改计算 = 准确性项 0.5·Σπ(σ−s)²（恒≥0）；新增 free_energy 字段 = 现有 F（可负，仅学习目标）——命名分离，负值不修，修的是命名。
2. Activation 追加 free_energy/per_dim_surprise/mse 三个带默认值字段 → 所有旧构造点与下游字段名零破坏，API/MCP/glue/回魂/self_pulse 全部无需改代码。
3. 移除 F/‖J‖（norm_surprise 降级为 no-op 弃用开关，属性保留防配置引用崩）——理由=无 FEP 依据 + 扭曲准确性项（v1.1 删除"F≥surprise 上界"论证）；J 范数钳制移出开关、无条件生效（参数 LMS_J_TARGET_NORM=40 不变）。
4. 逐维惊讶度 π_i(σ_i−s_i)² 在 infer() 内算好写入 Activation；purpose 优先读取，None 时回退 |σ| 代理（旧测试自动通过）；`per_dim_surprise_scale`（k）落地时按实测分布校准（必做）。
5. 做梦零精度陷阱（π=0 ⇒ surprise 恒 0）：做梦 surprise 改为对种子记忆的重构误差 0.5·Σ(σ−seed)²，语义=回放漂移越大越值得巩固。
6. 做梦 softmax 输入做缓冲区内标准化（z-score）+ **z 截断 clamp(±3)** + **β 默认降至 1.0**（(a)+(b) 组合，审计推荐），防准确性项 O(1~100) 量级与重尾离群（z≈10）下退化为 argmax 采样。
7. 下游四处：memory 回放排序/权重、meta 趋势因 ≥0 自动正确（仅文档）；真正代码改动只在 purpose（per_dim 映射 + 两个缩放参数，其中全局缩放 sigmoid(surprise/20) 为**必做**——C5 的对偶）与 dream（陷阱 + 标准化）。
8. glue integration_service.py 的 surprise/20 归一化**定为独立必做 commit G1**（memory-integration-layer 仓库，窗口 min-max 替换 /20，消除负值惩罚缺陷 + 防饱和；可后置不取消）。
9. 测试：至少 2 个断言确定迁移（attractor 自由能测试改用 free_energy 字段）+ **phase3_emergence 多个定量断言（含 4 个 slow 长实验）需运行验证、可能按新语义调整（尤其做梦尖峰测试）**；新增 12 项针对性测试（≥0、分解自洽、排序差异、钳制无条件、回放非零、softmax 非退化 + 单离群重尾、全局缩放不饱和、契约兼容等）。
10. Bregman 完整 VFE（v2 eq.(13/14) 逐节点 VFE + eq.(25) + CB log-normalizer）本期不做，记后续项；落地按 C1→C5 依序 + G1（glue 独立仓库）分批、每批可独立 git 回滚。
