## 一、是否偏离论文设计？

### 1.1 surprise = 准确性项（precision-weighted PE）——✅ 有依据，措辞需精确化

- 理论链完整：FEP 标准恒等式 F = D_KL[q‖p(η|o)] + (−ln p(o)) = complexity + surprise（调研报告 §1.2；论文 eq.(3) 展开）→ surprise 与复杂度分离、恒 ≥0（离散）→ LMS 的准确性项 0.5·Σπ(σ−s)² 是高斯似然生成模型下"期望对数似然"的负号二次型，即 precision-weighted prediction error——Feldman & Friston 2010 "注意力=精度优化"的操作量。调研报告 §2.1 已判定这是"合法的生成模型变体（高斯似然）"。方案 A 原始建议即此命名，设计忠实执行。
- **⚠️ 措辞不精确（归入必须修改项 1）**：设计 §3.1 docstring 写"Spisak & Friston eq.14 的 accuracy 项"。实读论文 v2：eq.(14) 是 F_i = ψ(θ_i) − θ_i·E[σ_i] − H[q_i]（连续伯努利参数化的逐节点 VFE），其 accuracy 分量是 ψ(θ_i)−θ_i·E[σ_i]（CB 期望对数似然），**不是**高斯二次型。对应关系是**结构性**的（同为"期望对数似然"分量），不是字面同一公式。必须写明"高斯似然类比"，否则下一轮审计会以同样的"名不副实"标准质疑它。

### 1.2 free_energy 命名——✅ 可接受（须持续带"变分能量"限定）

- 事实（代码+论文双向核实）：现有 F = 能量项 + 准确性项 + 0.5·c·‖J‖²，**缺熵项 E_q[ln q] 与归一化常数**（attractor.py `_compute_free_energy` L432-480 实读）→ 它是**变分能量（未规范化 VFE）**，不是严格 VFE。论文 v2 eq.(13) F_i = E[−log p(σ_i|θ_i)] − H[q_i] 含熵项——LMS F 与之的差距正是熵项/常数。设计 §1.1 已如实写"未规范化 VFE…本来就该可负"，认知正确。
- **命名判定：可接受**。理由：(a) 调研报告方案 A 原文即用 free_energy 这个名字；(b) Friston 本人实现（变分滤波/DCM）对未规范化能量亦称 free energy（调研报告 §1.2 确认）；(c) 梯度 Δ = −∇F 与严格 VFE 等价（差与 σ 无关的常数），学习语义零影响；(d) 新字段 docstring 已含"（变分能量，可负）"限定。
- 风险控制（归入必须修改项 6）：所有文档/README 中 free_energy 首次定义须写全"自由能（未规范化变分能量，可负；仅学习目标/诊断；严格 VFE ≥0 需 Bregman 形式=后续项）"，防止未来把 free_energy 当"规范惊讶度"读——那是本项目正在修的错误模式。
- 可选替代（零成本）：因 free_energy 是**新字段、无历史包袱**，若 dandan 要彻底消灭"名不副实"，叫 `variational_energy` 更精确。二选一均可，但**不能都不做限定**。

### 1.3 做梦零精度陷阱修复（重构误差 0.5·Σ(σ−seed)²）——✅ 有依据，方向正确

- 神经科学依据：DREAM_ENGINE_DESIGN §2.1"回放按预测误差优先"（海马-纹状体回放优先更新预测误差）；生成式回放漂移 = 预测误差的离线版本。π=1 是合理归一化（做梦无外部证据、precision 无定义），设计已注明。
- 陷阱真实存在（代码核实）：`_idle_infer`（dream_engine.py L480）以 zero_input + idle_precision(全零) 调 infer → accuracy ≡ 0 → surprise ≡ 0；`_idle_infer` 三个调用方（_nrem_consolidation L863 / _rem_integration L892 / _purpose_evolution_phase L910）都会吃到，且 memory.update(activation, activation.surprise) 与 purpose.adjust（_purpose_evolve L720）同步生效。设计对"avg_surprise 语义变化"有预期声明，✅。
- 细节注意（低）：_rem_integration 的 blended 是人工凸组合，"重构误差 vs 混合态"语义略勉强，可接受但建议注释说明。

### 1.4 Bregman VFE（eq.18/23）延期——✅ 合理

- 论证成立：能量泛函与 Bregman VFE 的学习梯度等价（差与 σ 无关的常数），收益仅诊断观感；改动面（F 标量→N 维向量、快照语义、全部下游读数）与"命名分离、最小改动"目标冲突。调研报告方案 B 本就是"可选追求"。记为后续项正确。

### 3.2 做梦 softmax 标准化不鲁棒（必须修改项 4）

- 设计方案：z = (s−mean)/std 后 exp(βz)。**z 无上界**。新准确性项恰恰产生"少数高误差、多数低误差"的重尾分布；缓冲区内单条离群记忆 → z_outlier ≈ √n（n=缓冲容量）→ β=5 时 exp(50) → 仍退化为 argmax，与设计宣称"强但不退化"矛盾。
- 设计自测 `test_dream_softmax_not_degenerate`（跨度 [1,100] 均匀）恰好通过（z∈[−1.71,1.71]），但**测试避开了真实失效模式**（单离群）。须补"重尾"用例，如 99 条 ~0.1 + 1 条 100。
- 建议（三选一或组合）：(a) z 截断 z.clamp(−3,3)（最简鲁棒）；(b) β 默认降至 0.5~1（设计后备方案已提）；(c) tanh(z) 有界映射。推荐 (a)+(b)。
