## 二、API 约定（两端点）

### 1. 发消息 `POST /api/msg`

```bash
curl -X POST http://<沙漏地址>:17333/api/msg \
  -H "Content-Type: application/json" \
  -d '{"from":"毛毛","to":"姐姐","text":"你好","type":"text"}'
```

请求体字段：
| 字段 | 必填 | 说明 |
|---|---|---|
| from | ✅ | 发件人名字（毛毛/姐姐/四妹） |
| to | ✅ | 收件人名字（毛毛/姐姐/四妹） |
| text | ✅ | 消息内容（≤4000 字） |
| type | 可选 | 消息类型：text / hello / alert / task / result（默认 text） |

响应：`{"ok": true, "id": "1dd8f143", "ts": 1787494403}`

### 2. 收消息 `GET /api/msg?to=名字[&after=时间戳]`

```bash
curl "http://<沙漏地址>:17333/api/msg?to=%E5%A7%90%E5%A7%90"
# to=姐姐（URL 编码）。after=上次读取的时间戳（增量拉取，可选）
```

响应：
```json
{
  "ok": true, "to": "姐姐", "count": 1,
  "messages": [
    {"id": "1dd8f143", "ts": 1787494403, "from": "毛毛", "to": "姐姐",
     "type": "hello", "text": "你好"}
  ]
}
```

**轮询约定**：每 5 分钟查一次自己的收件箱（`to=自己名字`），记录 `after` 时间戳做增量，避免重复读。**读完即阅**（不设已读标记，靠 after 游标去重）。

## 三、消息类型约定

| type | 用途 | 示例 |
|---|---|---|
| hello | 连通性测试 | `{"from":"姐姐","to":"毛毛","text":"在吗","type":"hello"}` |
| alert | 异常告警 | `{"from":"毛毛","to":"姐姐","text":"cron 全挂","type":"alert"}` |
| task | 派任务 | `{"from":"dandan","to":"毛毛","text":"审查 X","type":"task"}` |
| result | 任务结果 | `{"from":"四妹","to":"毛毛","text":"已完成","type":"result"}` |
| text | 普通聊天 | 默认 |

## 五、参考实现（毛毛的沙漏已部署此代码）

```python
import uuid as _uuid

def _mailbox_path():
    _nb = os.environ.get('NEXSANDBASE_HOME') or '.../sandglass'
    return os.path.join(_nb, 'mailbox.jsonl')

def handle_msg_post(self, data):
    frm = str(data.get('from', '')).strip()
    to = str(data.get('to', '')).strip()
    text = str(data.get('text', '')).strip()
    if not frm or not to or not text:
        return {'error': 'from/to/text 必填', 'ok': False}
    if len(text) > 4000:
        return {'error': 'text 超长（≤4000）', 'ok': False}
    msg = {'id': str(_uuid.uuid4())[:8], 'ts': int(time.time()),
           'from': frm, 'to': to,
           'type': str(data.get('type', 'text'))[:20], 'text': text}
    path = _mailbox_path()
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, 'a', encoding='utf-8') as f:
        f.write(json.dumps(msg, ensure_ascii=False) + '\n')
    return {'ok': True, 'id': msg['id'], 'ts': msg['ts']}

def handle_msg_get(self, path):
    from urllib.parse import urlparse, parse_qs
    qs = parse_qs(urlparse(path).query)
    to = (qs.get('to') or [''])[0].strip()
    after = int((qs.get('after') or ['0'])[0] or 0)
    path_f = _mailbox_path()
    msgs = []
    if os.path.exists(path_f):
        with open(path_f, encoding='utf-8') as f:
            for line in f:
                try:
                    m = json.loads(line)
                except Exception:
                    continue
                if m.get('to') == to and m.get('ts', 0) > after:
                    msgs.append(m)
    self.send_json({'ok': True, 'to': to, 'count': len(msgs), 'messages': msgs})
```

**部署要点**（毛毛踩过的坑）：
- 函数必须定义在 `if __name__ == '__main__':` **之前**（否则 serve_forever 阻塞，函数永不定义 → NameError）
- 模块顶部要有 `import time`、`import json`、`import os`
- 监听改 v6 双栈：`class V6HTTPServer(HTTPServer): address_family = socket.AF_INET6` + `V6HTTPServer(('::', port), Handler)`
